mahjong-tile-reader v0.3

手牌リーダー

並んだ手牌の画像を、機械学習なしで「123m456p…」の文字列に読み取ります。牌の表面を16×20のマスに分け、各マスの暗さ・赤み・緑み・青みを基準牌と比べています。色をしきい値で分けないので、JPEGやぼかしで赤や緑が黒に化けません。さらに基準なしの「規則」でも読みます。筒子・索子は粒の数・並び・赤の位置・中心線の余白、字牌は白の配置（北は縦の白線、南は真ん中の穴、東は左下が斜めに欠ける など）。答えが食い違えば自信なしにします。

自分の画像で読む

絵柄はゲームや牌セットごとに違うので、まず同じ絵柄の牌を1列並べた画像で基準を登録します。34種を何回かに分けて登録しても構いません（足りない牌は読めません）。

手牌の画像を選ぶ

手牌の部分だけを切り抜いた画像だと確実です。読んだ結果は上の表示に出ます。

精度の目安

サンプル絵柄の手牌400組（牌の高さ34〜130px、ぼかし・明るさ・色かぶり・ノイズ、半数はJPEG品質50〜90%）での牌の正解率です。基準はいつも絵柄Aで登録しています。

条件正解率メモ
同じ絵柄（組み合わせ・既定）99.85%手牌まるごと正解 98.2%
暗い赤・暗い緑の絵柄99.78%v0.1 は 98.40%
違う絵柄・見比べだけ95.43%一索→北、七萬→九萬 など
違う絵柄・組み合わせ95.51%残る誤りの9割に「自信なし」表示
規則だけ（基準なし）約64%残りは「?」。誤りは0.1〜0.2%

規則で読めるのは、筒子・索子（一索を除く）・一〜三萬・字牌7種です。四〜九萬と一索は字や絵の細かい形なので、見比べに任せています。違う絵柄で残る誤りはこの範囲に集中しているので、使う絵柄で基準を登録すれば解消します。

コードから使う

import { createReader } from './mahjong-tile-reader.js';

const reader = createReader();
// 同じ絵柄の牌を1列並べた画像で基準を登録（img / canvas / ImageData）
reader.addReferenceRow(refImage, '123456789m123456789p123456789s1234567z');

const result = reader.readHand(handImage);   // { count: 13 } で枚数指定も可
result.text;        // "123m456p789s11z..."
result.uncertain;   // 自信のない牌の位置

// 基準は JSON にして保存・再利用できます
localStorage.setItem('refs', JSON.stringify(reader.exportReferences()));
